# HEH-Doodles

The doodles from Homework Launchpad, at **doodles.civilinitiatives.org**: Bubble Tea,
Snake, Hop Runner, Brick Breaker, Bubble Float, Whack-a-mole, Tower Stack, Colour Echo,
Star Catch, Pairs, Bomb Squad, Noughts & Crosses, Quick Draw and Fruit Slash.
Little games just for fun - no questions, nothing sent to the server. Best scores
stay on the device.

Open one straight away with a link like `#snake`, `#breakout`, `#mole`, `#echo`,
`#katch`, `#pairs`, `#fruit`, `#boba`,
`#hop`, `#float`, `#ttt`, `#mines`, `#stack` or `#quick`.

Open to accounts that have all games switched on. Everyone else gets the site's
404 page. Sign-in and the games lock come from the main site, civilinitiatives.org.
